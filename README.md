# Daniel Edward Wilson - Portfolio Website

Personal portfolio website showcasing writing, video production, and professional background.

## Live Site
[danieledwardwilson.com](https://danieledwardwilson.com)

## Features
- Responsive design with Tailwind CSS
- Writing portfolio with categorized articles
- Video portfolio with embedded content
- Professional resume/CV
- Contact form

## Tech Stack
- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript
- Static site (no backend required)

## Deployment
Hosted on Vercel with automatic deployments from GitHub.
